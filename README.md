## 💡 Featured Projects | Projetos em Destaque

### 🩸 HemoConexão

<p align="center">
  <img
    src="https://raw.githubusercontent.com/LeticiaVicenteTeodoro/HemoConexao/main/file_000000002060820e9c7b1aa1db706da9.png"
    alt="HemoConexão - Telas do aplicativo"
    width="85%"
  />
</p>

**Doe sangue, salve vidas. Tudo o que você precisa para doar, em um só lugar.**

Aplicativo mobile que conecta doadores de sangue e hemocentros, facilitando o acesso às informações sobre estoques, agendamentos e histórico de doações.

**Principais funcionalidades:**
- 🩸 Consulta de estoques de sangue.
- 📍 Localização de hemocentros próximos.
- 📅 Agendamento e registro de doações.
- 🔔 Notificações sobre estoques críticos.
- 💬 FAQ e chat para dúvidas.
- 🔐 Autenticação de usuários.

**Tecnologias utilizadas:**

`React Native` `Expo` `TypeScript` `JavaScript` `Firebase` `FastAPI` `Python` `Node.js` `Express` `SQLite` `Selenium` `Docker`

### 🩸 API Aberta — Estoques de Sangue BR

API desenvolvida para disponibilizar informações sobre estoques de sangue de hemocentros brasileiros, permitindo consultas e integração desses dados em outras aplicações.

**Destaques:**
- 🔗 Integração de informações de diferentes hemocentros.
- 📊 Consulta de estoques de sangue.
- ⚙️ Estrutura organizada em serviços e rotas.
- 🔄 Coleta e atualização de informações.

**Tecnologias utilizadas:**

`Python` `FastAPI` `SQLite` `APIs REST`
